# Kendi Kendine Tartışan Varlıksal Felsefeci

## Bu Repo Nedir?

Bu, insanlık tarihinin en ciddi ve aynı zamanda en saçma projesidir. Bir Python scripti, kendi kendine varlıksal sorular sorar, kendi kendine cevap verir ve sonunda çay içmeye karar verir.

Neden var? Çünkü biri "githubda saçma bişey olsun" dedi ve burada işte.

## Nasıl Çalışır?

1. Python 3 kurulu olsun (yoksa kur, yoksa pişman olursun).
2. `python felsefeci.py` yaz.
3. Script kendi kendine konuşsun, sen izle.
4. Çıktıyı oku, gül, sonra "neden bunu yaptım" diye düşün.

## Özellikler

- Gerçekten çalışır.
- Hiçbir şeyi çözmez.
- Çay önerir.
- Abartılı derecede felsefi görünür ama değildir.
